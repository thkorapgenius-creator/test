# Mon Budget 💶

Application web de gestion de budget personnel, 100 % locale (aucun serveur, aucun compte) : vos données restent dans votre navigateur.

## Utilisation

Ouvrez `index.html` dans un navigateur (double-clic), ou hébergez le dossier (ex. GitHub Pages) pour l'installer sur votre téléphone via « Ajouter à l'écran d'accueil ».

Pour découvrir l'appli : **Réglages → Charger des données d'exemple**.

## Fonctionnalités

- **Accueil** : revenus, dépenses, montants mis de côté et **reste à vivre** du mois (avec le montant disponible par jour), budgets par catégorie, répartition des dépenses, évolution sur 6 mois.
- **Opérations** : ajout rapide de dépenses et de revenus (bouton `+`), recherche, filtres par type et par catégorie, regroupement par jour.
- **Budgets** : un plafond mensuel par catégorie, avec alerte en cas de dépassement, et un « plan du mois » (revenus − budgets − épargne prévue = montant non attribué).
- **Épargne** : objectifs (épargne de précaution, vacances, voiture…) avec montant cible et échéance. L'appli calcule **combien mettre de côté chaque mois** pour tenir l'échéance. Mise de côté ou retrait en un clic, et bouton « Répartir le plan » pour alimenter tous les objectifs d'un coup.
- **Fixes** : salaire, loyer, abonnements, virements d'épargne automatiques… Chaque mois, l'appli propose de les ajouter en un clic.
- **Réglages** : devise, sauvegarde et restauration (JSON), export du mois en CSV pour Excel.

> ⚠️ Les données sont stockées dans le navigateur de l'appareil. Exportez régulièrement une sauvegarde (Réglages) et utilisez-la pour passer d'un appareil à l'autre.
